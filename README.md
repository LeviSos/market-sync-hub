# Case Craft Studio

Role: Principal Full-Stack Engineer & GameDev Architect Specialist (Gambling/Gamedev/Steam Platform Ecosystems).Task: Create a complete, production-ready, highly scalable, and fully functional Counter-Strike 2 (CS2) item opening, battles, contracts, and upgrade web application inspired by Case-Battle.ac and Upgrader.pro, equipped with an enterprise-grade Administrative Dashboard (Admin Panel).1. SYSTEM ARCHITECTURE & TECH STACKFrontend Framework: Next.js (React) / TypeScript with Tailwind CSS, Framer Motion, and Canvas/WebGL (three.js or PixiJS for smooth 60fps roulette and upgrade wheel rendering).Backend Framework: Node.js (NestJS or Express with Clean Architecture) / TypeScript.Real-time Communication: Socket.io / WebSockets for multi-user synchronization, live case battles, live global drop feeds, and instant administrative controls.Databases:Primary DB: PostgreSQL (Prisma ORM or TypeORM) with ACID transactions for financial ledger, inventory management, user profiles, and audit logs.In-Memory / Cache: Redis for pub/sub (WebSockets), active game rooms, session storage, rate limiting, and price caching.External Integrations:Steam OpenID 2.0: Complete Steam authentication flow (SteamID64, profile details, trade URL validation).CS2 Item Price API Integration: Automated parser/fetcher module for item databases, images, exterior conditions (FN, MW, FT, WW, BS), StatTrak variants, Souvenir variants, and price syncing via APIs (e.g., PriceEmpire, CSGOTrader, or Steam Market API).Architecture Pattern: Modular Monolith or Microservices-ready structure with strict separation of concerns (Auth, Ledger, Inventory, Engine, Admin, Audit).2.
